MCP Server 激活方式

由 MCP 客户端按需通过 stdio 启动，不需要单独运行常驻服务。

  1. 在客户端配置 chrome-bridge-mcp。
  2. 客户端发起 MCP 请求时自动启动 Server。
  3. Server 通过 Native Messaging 激活本扩展。
node ./bin/chrome-bridge.mjs mcp-config --client <客户端>

可用 Claude Code、Cursor、Codex、VS Code、Windsurf/Cascade、Hermes Agent 等 MCP 客户端。

MCP Servers 配置 JSON
{
  "mcpServers": {
    "chrome-bridge": {
      "command": "node",
      "args": [
        "/absolute/path/to/codex-chrome-bridge/mcp/chrome-bridge-mcp.mjs"
      ]
    }
  }
}
